Investment-Research Agent  ·  Uteki
Project: v1  |  v2  |  v3
Investment-research decision infrastructure for S&P 500 / Nasdaq 100 high-quality companies — audit-ready, replayable, quantitatively evaluable; produces structured dossiers and decision-evidence chains as trustworthy ground truth for strategy validation.
Core design principles
  • Evidence before conclusion — Agent does not output verdicts directly; it first builds a SourceCatalog unifying financials, market data, news, and search results into DataPoints carrying source, timestamp, confidence
  • Staged reasoning — decompose company research into a 7-Gate decision chain: Business Quality → Fisher Growth → Buffett Moat → Munger Management → Inversion Test → Valuation → Synthesis
  • Constrained autonomy — each gate can call tools, but output must contain structured conclusion + confidence + [src:N] citations; parser validates citation legitimacy, blocking unsourced reasoning
  • Temporal consistency — as_of time-window constrains data and source timestamps for honest historical backtesting, strictly preventing lookahead bias
  • Observability & evaluability — persistent execution trace, gate output, tool calls, citations for replay audit; ConsistencyRunner and Arena measure run-to-run stability
Engineering
