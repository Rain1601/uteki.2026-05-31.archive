投研 Agent · Uteki（雨滴）
项目链接： v1 ｜ v2 ｜ v3
面向 标普 500 / Nasdaq 100 高质量公司构建可审计、可回放、可评估的投研决策基础设施 —— 输出结构化 dossier 与决策证据链，为策略实证提供可信 ground truth。
核心设计原则
  • 证据先于结论：Agent 不直接生成投资判断，而是先构建 SourceCatalog，将财报、市场数据、新闻和搜索结果统一为带来源、时间、置信度的 DataPoint
  • 分阶段推理：将公司研究拆解为 7-Gate 决策链 —— 业务质量 → Fisher 增长 → Buffett 护城河 → Munger 管理层 → 反向测试 → 估值 → 综合裁决
  • 受约束的自主性：每个 Gate 可调用工具，但输出必须包含结构化结论、置信度和 [src:N] 引用；parser 校验引用合法性，避免无来源推理
  • 时间一致性：引入 as_of 时间窗约束数据和来源时间，支持历史回测，严格避免 lookahead bias
  • 可观察与可评估：持久化 execution trace、gate output、tool calls 和 citation，支持 replay 审计；通过 ConsistencyRunner 和 Arena 评估多次运行稳定性
工程实现
  • FastAPI + React + Pydantic 构建完整工作台 —— SSE 流式执行 / 运行记录 / 断线恢复 / 结果回放；Reflection Checkpoint 跨 Gate 矛盾检测；Arena 3-phase（Decide → Vote → Tally）多 LLM 匿名互评
