### 投研 Agent · Uteki（雨滴）

项目链接：v1 [uteki.v1.archive](https://github.com/Rain1601/uteki.v1.archive) ｜ v2 [uteki.v2](https://github.com/Rain1601/uteki.v2) ｜ v3 [uteki](https://github.com/Rain1601/uteki)

面向 **标普 500 / Nasdaq 100** 中"清晰可见"的高质量公司，构建**可审计、可回放、可评估**的投研 Agent。

**核心设计原则**

- **证据先于结论** — Agent 不直接生成投资判断，而是先构建 SourceCatalog，将财报、市场数据、新闻和搜索结果统一为带来源、时间、置信度的 DataPoint
- **分阶段推理** — 将公司研究拆解为 7-Gate 决策链：**业务质量 → Fisher 增长 → Buffett 护城河 → Munger 管理层 → 反向测试 → 估值 → 综合裁决**
- **受约束的自主性** — 每个 Gate 可以调用工具，但输出必须包含结构化结论、置信度和 `[src:N]` 引用；parser 校验引用合法性，避免无来源推理
- **时间一致性** — 引入 `as_of` 时间窗约束数据和来源时间，支持历史回测，**严格避免 lookahead bias**
- **可观察与可评估** — 持久化 execution trace、gate output、tool calls 和 citation，支持 replay 审计；通过 **ConsistencyRunner** 和 **Arena** 评估多次运行稳定性

**工程实现**

- FastAPI + React 构建完整 Agent 工作台，支持 SSE 流式执行、运行记录、断线恢复、结果回放
- Pydantic 约束每个 Gate 的结构化输出，降低自由文本不可控问题
- Reflection Checkpoint 检测跨 Gate 矛盾，并将上游结论作为下游推理上下文
- Arena 3-phase（**Decide → Vote → Tally**），多 LLM 独立判断 + 匿名互评，提高结论稳定性

### 投研 Agent · Shinkai（深海 · 进行中）

项目链接：[github.com/Rain1601/shinkai](https://github.com/Rain1601/shinkai)

面向"市场尚未充分覆盖"的潜在优质公司，探索从**公司发现 → 初筛 → 假设生成 → 深度研究**的主动式投研 Agent。

- **与 Uteki 的差异** — Uteki 偏深度审计已知公司，Shinkai 偏**主动发现未知机会**，构成 Research → Discovery 完整闭环
- **候选池发现流程** — 从财务质量、增长异常、估值错配、行业变化和市场忽视信号中生成研究对象
- **Hypothesis-first 研究链路** — 先生成投资假设，再反向搜索证据验证或证伪，避免只做信息汇总
- 目标形成 **发现 → 假设 → 证据 → 反证 → 深度研究** 端到端投研 Agent 流程
